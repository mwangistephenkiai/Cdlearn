CodeLearn

A Flutter mobile app for learning **HTML**, **JavaScript**, **React.js**, and **PHP**.  
Includes interactive lessons, syntax-highlighted code examples, quizzes, and Firebase Authentication.

Features
- 4 programming tracks with structured lessons
- Syntax-highlighted code examples
- Interactive quizzes with instant feedback
- Firebase Auth (Email/Password)
- Cloud progress sync via Firestore
- Modern Material 3 UI

Setup

Create a Flutter project
   ```bash
   flutter create codelearn
   cd codelearn
